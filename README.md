# ⚽ Quiniela Mundial 2026

Tu quiniela familiar para el Mundial FIFA 2026.
Sigue estos pasos para publicar tu sitio web — todo gratis.

---

## Paso 1: Crea una cuenta en GitHub (5 min)

1. Ve a **https://github.com/signup**
2. Ingresa tu email, crea una contraseña
3. Elige un nombre de usuario (ej: `gianni-quiniela`)
4. Verifica tu email
5. ¡Listo!

---

## Paso 2: Crea un proyecto en Firebase (5 min)

Firebase es la base de datos gratuita donde se guardan las predicciones de todos.

1. Ve a **https://console.firebase.google.com**
2. Inicia sesión con tu cuenta de Google
3. Clic en **"Agregar proyecto"** → Nombre: `quiniela-mundial-2026`
4. Desactiva Google Analytics (no lo necesitas) → **Crear proyecto**
5. En el menú izquierdo: **Build → Realtime Database → Crear base de datos**
6. Elige **"Iniciar en modo de prueba"** → Siguiente → Activar
7. En el menú izquierdo: **Configuración del proyecto** (ícono de engranaje)
8. Baja a **"Tus apps"** → Clic en el ícono web **`</>`**
9. Nombre: `quiniela` → **Registrar app**
10. **COPIA los valores** de `firebaseConfig` que aparecen
11. Abre el archivo `src/firebase.js` de este proyecto y **reemplaza** los valores placeholder con los tuyos

---

## Paso 3: Sube el código a GitHub (3 min)

1. Ve a **https://github.com/new**
2. Nombre del repositorio: `quiniela-mundial-2026`
3. Marca **"Public"** → Clic **"Create repository"**
4. En tu computadora, sube todos los archivos de esta carpeta al repositorio
   - Puedes arrastrar los archivos directamente en la página de GitHub
   - O usar el botón **"uploading an existing file"**

---

## Paso 4: Publica con Vercel (3 min)

1. Ve a **https://vercel.com/signup**
2. Clic en **"Continue with GitHub"** → Autoriza
3. Clic en **"Import Project"** → Selecciona `quiniela-mundial-2026`
4. Vercel detecta automáticamente que es un proyecto Vite
5. Clic en **"Deploy"** → ¡Espera ~1 minuto!
6. Vercel te da un link como: **https://quiniela-mundial-2026.vercel.app**
7. ¡Ese es tu link! Compártelo con familia y amigos 🎉

---

## Cómo funciona

- **Código de invitación:** `Mundi@l2026$!`
- **Código admin:** `admin2026` (para cargar resultados)
- Cada participante entra con el código, elige su nickname y avatar
- Todos ven la misma tabla de posiciones en tiempo real
- El admin carga los resultados y los puntos se calculan automáticamente

## Sistema de puntuación

| Acierto | Puntos |
|---------|--------|
| Resultado correcto (G/E/P) | 3 pts |
| Marcador exacto | 10 pts |
| Campeón correcto | 25 pts |
| Subcampeón correcto | 15 pts |
| Goleador correcto | 20 pts |

### Multiplicadores por fase
- Grupos: 1× | 16avos: 2× | Octavos: 3× | Cuartos: 5× | Final: 10×
- Comodín: 2× adicional (1 por fase)
